# Abdullah Basit — Full Stack & AI Engineer Portfolio

A production-grade, interactive portfolio website engineered for **Abdullah Basit** (COMSATS University Islamabad, BS Electrical Engineering / Computer Engineering 2026).

Built with **React 19**, **Three.js (WebGL)**, **Framer Motion**, **Tailwind CSS**, and serverless AI endpoints.

---

## 🌟 Key Features

1. **Procedural 3D Hero Lattice (Three.js WebGL)**
   - Interactive icosahedron wireframe, inner reflective core, gyroscopic orbital rings, and neural constellation nodes with exponential pointer damping.
   - iOS Safari WebKit crash-proof guards and graceful ambient CSS glow fallback.

2. **Framer Motion 3D Tilt Cards**
   - Physics-damped spring tilt (`rotateX`, `rotateY`, `scale3d`) that responds to real-time mouse offset with dynamic specular glare sheen.
   - Touch-safe optimization for mobile devices and iPhones to prevent WebKit composite layer bugs.

3. **Curated Case Studies with Interactive Mockups**
   - Rich interactive mockups for all 7 production projects (University Management Portal, AI Interview Coach, RAG PDF Chatbot, AI Omnichannel SaaS, Hostel & Clinic Management, TalkPool LTE KPI Dashboard, and Skin Disease Detection FYP).
   - Deep architectural breakdown modals with problem statements, engineering contributions, and direct GitHub links.

4. **Technical Arsenal with Verified SVG Brand Icons**
   - Frontend, Backend, Python, AI/LLMs/RAG, Databases, and DevOps with official brand badges and proficiency levels.

5. **Integrated WhatsApp Channels & In-App Resume**
   - Floating WhatsApp button (`#25D366`), dedicated Contact section card, Navbar badge, and Hero action linking directly to `+92 331 555 2232`.
   - Accessible in-browser Curriculum Vitae modal with native Print / Save to PDF stylesheet.

6. **Smart AI Assistant with Offline Resilience**
   - Serverless endpoint supporting Groq (`llama-3.3-70b-versatile`) and Gemini Flash with an embedded knowledge engine fallback so it never 500s or returns empty answers.

## 🚀 How to Push to GitHub & Deploy on Vercel

### Step 1: Download & Extract the Code
You can download the clean project zip directly from:
`https://ais-dev-ja35twhhlzyvm6ouii5zqi-40286839997.asia-east1.run.app/portfolio-source.zip`
*(Or use the Export button in Google AI Studio)*

Extract the files into your local repository folder (`portfolio/`).

### Step 2: Push to GitHub
Open your terminal in your portfolio directory and run:

```bash
git add .
git commit -m "feat: complete redesign with 3D canvas, framer-motion cards, WhatsApp integration, and iOS compatibility"
git push origin main
```

### Step 3: Vercel Automatic Deployment
Since your GitHub repository is connected to Vercel, Vercel will automatically:
1. Detect the new commit on `main`.
2. Run `npm run build` using the updated scripts.
3. Deploy the live site to `https://abdullahbasit.vercel.app/` in under 60 seconds!
